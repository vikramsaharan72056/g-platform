# G-Platform

> Full-stack TypeScript platform with async event-driven pipelines, real-time features, and monorepo architecture.

## Overview

G-Platform is a production-grade full-stack application built with modern tooling. It features async event-driven pipelines, real-time capabilities, and is containerised for reliable cloud deployment.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| **Frontend** | React, TypeScript, CSS |
| **Backend** | NestJS, Node.js, TypeScript |
| **Database** | PostgreSQL, Supabase |
| **Infrastructure** | Docker, AWS |
| **Architecture** | Monorepo, Event-Driven, Async Pipelines |

## Project Structure

```
g-platform/
├── apps/           # Frontend & backend applications
├── packages/       # Shared libraries and utilities
├── docker/         # Docker configuration files
├── docs/           # Project documentation
└── tests/          # End-to-end and integration tests
```

## Key Features

- **Async Event-Driven Architecture** — Decoupled pipelines for reliability and scalability
- **Real-Time Capabilities** — Live data updates across connected clients
- **Monorepo Structure** — Shared packages and consistent tooling across apps
- **Containerised Deployment** — Docker-based setup for consistent environments
- **TypeScript End-to-End** — Strict typing across frontend and backend

## Getting Started

```bash
# Install dependencies
npm install

# Start development environment
npm run dev

# Run with Docker
docker-compose up
```
